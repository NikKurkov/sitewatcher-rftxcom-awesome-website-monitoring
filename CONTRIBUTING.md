# Contributing to Awesome Website Monitoring

Thanks for taking the time to contribute!

## How to Contribute

### Adding a Tool or Service

1. Fork this repository
2. Add your tool to the appropriate category
3. Use this format:
   ```markdown
   - [Tool Name](https://example.com) - Brief description (max 100 chars).
   ```
4. Keep descriptions factual, not marketing
5. Submit a pull request

### Guidelines

- **Quality over quantity** - Only add tools you've used or can vouch for
- **Active projects** - Must be actively maintained (updated within last year)
- **Free tier preferred** - For paid services, prefer those with free tiers
- **No duplicates** - Check existing entries first
- **Alphabetical order** - Within each category

### What We're Looking For

- Open source tools
- Free or freemium services
- Useful CLI tools
- Browser extensions that help with monitoring
- Educational resources

### What We Don't Accept

- Tools that haven't been updated in 2+ years
- Services without free tiers (unless exceptional)
- Duplicates of existing tools
- Self-promotional additions without disclosure
- Broken links

## Code of Conduct

Be respectful. This is a curated list, not a dumping ground.

## Questions?

Open an issue if you're unsure whether something fits.
